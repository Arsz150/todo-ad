# ✅ Сервис To-do

Одностраничное приложение для управления списком задач. Позволяет добавлять, просматривать, удалять, копировать и редактировать задачи, а также сохранять их в локальном хранилище браузера.

## О проекте

«Сервис To-do» — простой и удобный планировщик задач, который помогает организовать повседневные дела и следить за их выполнением.

Пользователь может:

* просматривать список текущих задач;
* добавлять новые задачи;
* удалять ненужные задачи;
* копировать существующие задачи;
* редактировать текст задач;
* сохранять список задач после перезагрузки страницы.

Проект выполнен в рамках обучения на курсе **Frontend-разработчик** от Яндекс Практикума.

## Технологии

* HTML5
* CSS3
* JavaScript (ES6)
* DOM API
* Local Storage
* Git
* GitHub

## Функциональность

* Отображение списка задач при загрузке приложения
* Добавление новых задач через форму
* Удаление выбранных задач
* Копирование задач с добавлением в начало списка
* Редактирование текста существующих задач
* Автоматическое сохранение изменений в Local Storage
* Восстановление списка задач после перезагрузки страницы
* Создание элементов списка на основе HTML-шаблона (`template`)

## Установка и запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/ВАШ-АККАУНТ/ВАШ-РЕПОЗИТОРИЙ.git
```

Перейдите в папку проекта:

```bash
cd ИМЯ-ПАПКИ-ПРОЕКТА
```

Откройте файл `index.html` в браузере.
